## 数据边界

## 检查与发布

需要 Node.js 22.13 或更新版本。运行 npm ci、npm test、npm run lint、npm run typecheck、npm run build:pages。后者生成 out/，并检查产物只含公开统计。仓库现有 GitHub Actions 会构建并部署 main。

源码同步脚本仅复制 public-source-files.json 明确列出的文件。新增公共源码需显式更新清单；原始训练文件永远不得放进此目录。不要提交 node_modules、环境文件、日志或构建缓存。

上线后核对网页 publicationId 与批准快照一致。Git 提交成功不等于部署成功。

## 公开快照 v4

白名单包括 schemaVersion、publicationId、updatedAt、summary、rounds、projects 和 curriculum。curriculum 只公开已确认的 28 项计划标题键、类别、相对周次、进度、准备状态及起步练习的公开关联。静态标题目录不包含具体题面、产物要求或评审依据。每轮只带独立公开编号、日期、类别、阶段、提示辅助/独立方式、用时及来源、规模/一致性/性能评估状态。项目只带独立公开编号、静态标题键、类别、状态、关联公开轮次、引导完成状态、正式交卷统计、独立考试统计和封闭评价枚举。不得导出私有练习编号、题目、答案、证据、精确消息时间戳或私有链接。

评价按优势、已澄清问题、待验证项和建议分类，由已审核的枚举映射到固定短句，不能自动透传原文或任意自由文本。初次通过序号只有真实独立验收支持时才能产生；零次考试必须显示尚未考核。六类存储方向及综合设计属于计划分组，不自动生成未开题的实际项目。

正式练习提交数包含完整提交的修订版，修订次数是子集，不能相加。独立考核只统计完整交卷，不把开始或草稿计作尝试。零次表示尚无完整独立交卷，不能据此断言从未开始。已评审不自动代表通过；模式明确的独立通过不增加 Demo 完成数，也不自动改变三维能力评估。轮次日期是记录日期，不能替代真实用时证据。

conversation_span 表示从首个本人参与消息到技术边界确认的对话跨度，按分钟四舍五入；可能含等待和离开，不是专注时长，后续文档/页面整理不计入。signal_interval 表示本人明确的开始与完成／提交通知之间的区间，扣除已知暂停；未报告的等待仍可能计入，不是精确专注时长。两种观察区间归入 estimatedMinutes，明细分别标注来源。user_confirmed 为本人另行确认的值。同一轮以确认值优先，只计一次；汇总区分确认与估算，没有该类别的数据时为 null。

公开编号独立于私有记录 ID，不能用私有 ID 或其散列生成。能力只展示已存在的评估状态，不从完成数、用时或参与方式推断分数。
